# Changelog

All notable changes to Pomofloat are documented here.

## [2.1.4] - 2026-10-09

### Added

- A `pomofloat --version` command that exits before creating a GUI.
- Release, contribution, security, and issue-tracking documentation.
- CI and tagged-release workflows.

### Changed

- Synchronized Python and Debian package versions at 2.1.4 / 2.1.4-1.
- Refreshed the project README and added setup and compact-mode screenshots.

### Preserved

- Existing timer behavior, UI, bundled icon, tray integration, and Wayland
  platform handling.
