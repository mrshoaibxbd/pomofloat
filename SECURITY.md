# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
[me@shoaib.bd](mailto:me@shoaib.bd) with:

1. A concise description of the vulnerability.
2. The affected Pomofloat version and Ubuntu version.
3. Reproduction steps or a minimal proof of concept.
4. The potential security impact.

Do not include passwords, private keys, personal data, or other secrets.
Please allow reasonable time for investigation and coordinated disclosure.

We will acknowledge a report as soon as practical, investigate it, and
coordinate a fix and disclosure timeline with the reporter.

## Scope

Pomofloat is a local desktop application. It does not provide a network
service or collect telemetry. Keep the application and system dependencies
updated, and only run packaging or installation commands you trust.
